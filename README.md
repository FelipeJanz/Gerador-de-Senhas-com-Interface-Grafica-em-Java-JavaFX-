Problema

Com o aumento da necessidade de segurança digital, muitos usuários ainda utilizam senhas fracas ou repetidas, o que representa um grande risco. Além disso, gerar senhas fortes
manualmente não é prático, especialmente para usuários que não possuem conhecimento técnico ou não sabem quais critérios tornam uma senha segura.

Solução

Para resolver esse problema, foi desenvolvido um gerador de senhas utilizando Java com interface gráfica em JavaFX. A aplicação permite que o usuário escolha o tamanho da senha
e selecione se deseja incluir números e caracteres especiais, gerando automaticamente uma senha aleatória e mais segura. A interface foi projetada para ser simples, intuitiva e 
acessível, facilitando o uso por qualquer pessoa.

Aprendizado

Durante o desenvolvimento deste projeto, foram aplicados conceitos importantes de programação em Java, como manipulação de strings, uso de geração aleatória segura e organização
de código. Também foi possível aprender na prática o uso do JavaFX para criação de interfaces gráficas, além de melhorar a separação entre lógica de negócio e interface. O projeto
contribuiu para uma melhor compreensão de boas práticas no desenvolvimento de aplicações e criação de soluções voltadas ao usuário.
